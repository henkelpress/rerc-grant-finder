Optional Windows tool

Meet RERC-e, your local grant-writing guide.

RERC-e helps you review likely matches and start a grant draft with your own notes.

The guide walks you through setup. You do not need an account, command line, or AI key. RERC-e checks its built-in community file first. If needed, you can add a free Census API key.

RERC-e is a community-built companion published by Timberwing Systems, an EPR, P.C. initiative. It is not an EPA grant program, does not determine eligibility, and does not submit applications.

The first time you use RERC-e, it downloads Google Gemma (about 0.81 GB). Before you apply, verify dates and rules on the official funding page.

Download RERC-e Windows 10 or 11, 64-bit. No command line. Download the latest public RERC-e installer. It is not code-signed. Windows may warn that the publisher is unknown. Read the Timberwing Systems license | Review the source
